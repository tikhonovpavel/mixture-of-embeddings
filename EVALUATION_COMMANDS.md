# Evaluation Commands for Separation Ability

## Описание

Этот скрипт (`evaluate_separation.py`) оценивает, насколько модель способна разделять смешанные тексты после дообучения.

### Метрика

Для каждой модели:
1. Берем пары текстов из датасета
2. Получаем эмбеддинги для каждого текста отдельно
3. Смешиваем их в пропорции **0.5:0.5** (λ=0.5)
4. Прогоняем смешанный эмбеддинг через модель
5. Измеряем **ранг правильного следующего токена из текста 1** в предсказанном распределении
6. Считаем среднее по всем токенам

**Меньший ранг = лучше разделение**. Если модель научилась лучше разделять тексты, то правильный токен должен иметь более высокий ранг (меньшее число) в смешанном распределении.

## Модели для проверки

Скрипт будет оценивать:

1. **Базовую модель** (HuggingFaceTB/SmolLM2-135M без дообучения)
2. **Дообученные модели** из трёх раннов:
   - `run_20251028_182407` (mixup_alpha=0.4) - шаги 40000, 80000
   - `run_20251030_145128` (mixup_alpha=1.0) - шаги 40000, 80000
   - `run_20251031_181041` (mixup_alpha=0.65) - шаги 40000, 80000

*(run_20251031_180549 исключён, так как не имеет чекпоинтов)*

## Команды для запуска

### Быстрая оценка (500 примеров)
```bash
 python evaluate_separation.py \
    --checkpoint_dir checkpoints \
    --runs run_20251028_182407 run_20251030_145128 run_20251031_181041 \
    --checkpoint_steps 40000 80000 \
    --num_samples 500 \
    --batch_size 8 \
    --device cuda:0 \
    --output_file separation_results_500samples.json
```

### Полная оценка (2000 примеров, более точная)

```bash

```

## Параметры

- `--checkpoint_dir`: Базовая директория с чекпоинтами (по умолчанию: `checkpoints`)
- `--runs`: Список раннов для оценки
- `--checkpoint_steps`: Шаги чекпоинтов для оценки (например: 40000 80000)
- `--num_samples`: Количество пар текстов для оценки (больше = точнее, но медленнее)
- `--max_length`: Максимальная длина последовательности (по умолчанию: 512)
- `--batch_size`: Размер батча (по умолчанию: 8)
- `--device`: Устройство для вычислений (по умолчанию: `cuda:0`)
- `--seed`: Seed для воспроизводимости (по умолчанию: 42)
- `--output_file`: Файл для сохранения результатов

## Выходные метрики

Для каждой модели скрипт вычисляет:

- **mean_rank**: Средний ранг правильного токена (ниже = лучше)
- **median_rank**: Медианный ранг (робастнее к выбросам)
- **std_rank**: Стандартное отклонение рангов
- **mrr**: Mean Reciprocal Rank (среднее 1/rank, выше = лучше)
- **top1_acc**: Доля случаев, когда правильный токен на 1-м месте
- **top5_acc**: Доля случаев, когда правильный токен в топ-5
- **top10_acc**: Доля случаев, когда правильный токен в топ-10
- **top50_acc**: Доля случаев, когда правильный токен в топ-50

## Интерпретация результатов

### Что мы ожидаем увидеть?

Если дообучение успешно, то:
- **Mean Rank должен уменьшиться** по сравнению с базовой моделью
- **MRR должен увеличиться**
- **Top-1/5/10 Accuracy должны увеличиться**

### Сравнение между моделями

Сравните модели с разными `mixup_alpha`:
- **alpha=0.4**: Более агрессивное смешивание (Beta(0.4, 0.4) дает больше веса краям)
- **alpha=1.0**: Равномерное смешивание (Beta(1.0, 1.0) = Uniform[0,1])
- **alpha=0.65**: Промежуточный вариант

Интересно посмотреть, какой alpha дает лучшее разделение.

## Примечания

- Скрипт автоматически сравнивает все чекпоинты с базовой моделью
- Результаты сохраняются в JSON-файл для дальнейшего анализа
- Используется один и тот же seed для всех моделей для честного сравнения
- Можно запускать на любой GPU, указав `--device cuda:N`
